# 세계의 미스터리 6화 · 버뮤다 삼각지대의 진실 (플라이트 19, 61초 · 실사 다큐 + 실제 사진)

- 본편 61초 + 맨 앞 썸네일 1.5초, 14장면 · 17문장, TTS `ko-KR-Chirp3-HD-Charon` 1.2배속
- 5화 `shorts/dancing-plague/`를 틀로 씀 (`archive()` · `real_tag()` · `photo()`)
- 대본 · 사실 확인 · 사진 출처 · TTS 검사: `script.md` / 업로드 정보: `youtube-metadata.md` / 콘티: `storyboard.html` · `.png`
- 완성 영상: `video/flight-19-shorts.mp4`, 썸네일: `thumbnail/thumbnail.png`

## 이번 편에 적용한 사용자 규칙

- 실제 사진 3장면(미 해군 · 해안 경비대, 공공 영역) + 지도 1장면(CC BY 2.5, 화면과 설명란에 출처), AI 영상 3장면, AI 사진 7장면
- 썸네일 전에 제목을 물어봄 (추천 후보 4개 → 「버뮤다 삼각지대의 진실」)
- 퀴즈 없음, 썸네일 포함 62.5초, 화면 위 라벨에 편 번호 없음

## 새로 만든 것: 끊겨도 다시 결제하지 않는 영상 요청

5화에서 작업 환경이 다시 시작되며 끊긴 영상 요청이 청구된 것으로 보여 `gen_footage.py`의 `clip()`을 바꿈:

- 영상은 **하나씩** 요청 (`/run` 비동기), 요청 번호를 `footage/jobs.json`에 **먼저 저장**한 뒤 기다림
- 다시 실행하면 저장된 번호의 상태를 이어서 확인 → 같은 요청의 결과를 받음. 이미 받은 클립(`footage/Sxx.mp4`)은 건너뜀
- 이번 편에서 실제로 환경이 다시 시작됐고, 두 번째 영상은 새로 결제하지 않고 이어받음

## 이번 편 메모

- 실제 사진은 사건 당시 것이 아니라 **같은 기종** 사진이라 화면 표시와 설명란에 그렇게 밝힘
- 「버뮤다」가 받아쓰기에서 「범위다」로 들려 「훗날, 버뮤다」로 쉼표를 넣음
- 「버뮤다 삼각지대의 출발점」이라고 하면 틀려서(1950 · 1952년 글이 먼저) 「대표 사례」로 말함
- 위키미디어 내려받기는 429가 잦음: `upload.wikimedia.org` 원본 주소가 막히면 `Special:FilePath/<파일>?width=1600`으로, 그 반대로도 시도. 40초 간격으로 다시 받는 반복문을 배경으로 돌림
- Seedream이 폭풍 바다를 두 번 옆으로 눕혀 그림 → 「물 바로 위 눈높이, 구름은 화면 위쪽」으로 고쳐 해결
