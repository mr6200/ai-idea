- 대본 · 사실 확인 · 사진 출처 · TTS 검사: `script.md` / 업로드 정보: `youtube-metadata.md` / 콘티: `storyboard.html` · `.png`
- 완성 영상: `video/roopkund-shorts.mp4`, 썸네일: `thumbnail/thumbnail.png`

## 이번 편에 적용한 사용자 규칙

- 실제 사진 3장면 (위키미디어 공용 CC BY-SA 4.0, 화면과 설명란에 작가 · 라이선스), AI 영상 3장면, AI 사진 6장면
- 썸네일 전에 제목을 물어봄 → 사용자가 직접 적은 「히말라야 호수 밑 수백 명의 뼈.. 정체는?」 (오타 「및」 → 「밑」)
- 퀴즈 없음, 썸네일 포함 59.5초, 화면 위 라벨에 편 번호 없음

## 이번 편 메모

- 위키미디어 공용 분류(`Category:Roopkund`)를 `generator=categorymembers` + `prop=imageinfo`로 한 번에 물어 라이선스까지 받음 (요청 수를 줄여 429 회피)
- 유해 사진은 자극적이지 않은 것만, AI 프롬프트에도 "gore, blood, flesh"를 빼도록 넣음
- 해발 고도가 자료마다 달라(5,020m · 4,536m) 「4,500m가 넘는」으로 말함
- 발음 경고 0줄
