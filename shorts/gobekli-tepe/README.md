# 세계의 미스터리 10화 · 피라미드보다 7,000년 앞선 신전 (괴베클리 테페, 62초 · 실사 다큐 + 실제 사진)

- 본편 62초 + 맨 앞 썸네일 1.5초, 13장면 · 16문장, TTS `ko-KR-Chirp3-HD-Charon` 1.2배속
- 9화 `shorts/pyramids/`를 틀로 씀 (영상 요청 번호 저장 · `archive()` · `real_tag()` · `photo()`)
- 대본 · 사실 확인 · 사진 출처 · TTS 검사: `script.md` / 업로드 정보: `youtube-metadata.md` / 콘티: `storyboard.html` · `.png`
- 완성 영상: `video/gobekli-tepe-shorts.mp4`, 썸네일: `thumbnail/thumbnail.png`

## 이번 편에 적용한 사용자 규칙

- 주제는 추천 후보 4개 중 사용자가 고름
- 실제 사진 7장면 (6장, CC BY · CC BY-SA, 화면과 설명란에 작가 · 라이선스), AI 영상 3장면, AI 사진 3장면
- 썸네일 전에 제목을 물어봄 → 추천안 「피라미드보다 7,000년 앞선 신전」
- 퀴즈 없음, 썸네일 포함 63.5초, 화면 위 라벨에 편 번호 없음

## 이번 편 메모

- 사진은 위키미디어 공용 분류 「Göbekli Tepe」와 하위 분류(구역 A · C · D, 지붕 이전)를 `generator=categorymembers`로 물어 라이선스 · 작가를 함께 받음. 독일고고학연구소(DAI)의 항공 사진(CC BY 4.0)은 기관 공식 사진이라 쓰지 않음
- 「신전」은 발굴자 슈미트의 해석이고 최근엔 마을이었다는 주장도 있어, 두 가지를 모두 말함. 일부러 묻었는지는 논쟁 중이라 다루지 않음
- 기둥 무게는 자료마다 8톤~50톤으로 달라 발굴단(DAI) 숫자 「10톤 가까이」를 씀
- Seedream이 「여우를 새긴 기둥」을 색칠한 그림으로 그려서, 색 없는 멧돼지 돌 조각으로 바꿈
