- 완성 영상: `video/dancing-plague-shorts.mp4`, 썸네일: `thumbnail/thumbnail.png`

## 이번 편에 적용한 사용자 규칙

- 실제 옛 그림 3장면 (공공 영역, 출처는 `script.md` · 설명란), AI 영상 3장면, AI 사진 5장면
- 썸네일 전에 제목을 물어봄 (추천 후보 4개 → 「멈추지 못한 춤, 1518년 춤 전염병」)
- 퀴즈 없음, 썸네일 포함 61.5초, 화면 위 라벨에 편 번호 없음

## 이번 편 메모

- **클립 앞부분만 쓰기 `prep_footage.TRIM`:** 마지막 장면 영상에서 3.5초부터 사람 다리가 들어와, 다시 만들지 않고 앞 3.3초만 늘려 씀
- 위키미디어 공용 API가 요청 횟수 제한(429)에 걸려, 영어 위키백과 API로 관련 글에 쓰인 그림 이름을 찾은 뒤 공용 API를 30초 간격으로 다시 물어 라이선스를 확인함
- 맥각 사진은 처음에 보라색 꽃처럼 그려져 「검고 길쭉한 뿔 모양 · 사람 없음」으로 다시 그림
- 사망자 수(「하루 15명」)는 당시 기록에 없어 넣지 않음
- 작업 환경이 두 번 다시 시작됨. 마지막 영상 요청 하나가 끊겨 다시 만들었음 (끊긴 요청이 청구됐을 수 있어 잔액으로 확인)

## RunPod 사용액

AI 사진 17장 약 $0.46 + WAN 2.2 클립 3개 $0.90 = 예상 약 $1.36. **실제 잔액 차이는 약 $2.23** ($22.16 → $19.94). 작업 환경이 다시 시작될 때 끊긴 영상 요청(들)이 청구된 것으로 보이며, 공개 엔드포인트 요금은 RunPod 청구 내역 API에 따로 나오지 않아 항목별로 확인할 수는 없었음.

cd build && ./build_all.sh --render
