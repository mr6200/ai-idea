# 쇼츠 #02 — 당신의 지갑을 여는 뇌의 착각 3가지

## 기획
- **형식**: 세로 1080×1920, 30fps, 60초 이내 (맨 앞 1.5초 썸네일 인트로 + 본편)
- **타깃**: 1편(뇌의 착각 3가지) 시청자, 소비·절약·심리 관심층
- **훅 전략**: "방금 산 그거, 당신이 고른 게 아닙니다" 1인칭 도발 → 번호 3개 → "이번 주 몇 개 당했나" 댓글 유도. 1편 마지막 항목(앵커링)을 잇는 소비 심리 시리즈 2편
- **비주얼**: 실사 사진(카드 결제 단말기, 팝콘, 마트 진열대, 마트 통로, 금화) + Three.js 3D 오브젝트
  - 훅: 금화 탑 + 떠다니는 카드 + 동전 비
  - 착각 1: 오렌지 3D "1" + S/M/L 3D 컵 + 가격 알약(M 강조)
  - 착각 2: 블루 3D "2" + 궤도를 도는 "9" 글리프 + 10,000원 취소선 → 9,900원
  - 착각 3: 레드 3D "3" + 떨어지는 선물상자 쌍(1+1) + "안 사면 손해?" 알약 강조
  - 아웃트로: 그린 3D "?" + 말풍선
- **음성**: Microsoft Edge TTS `ko-KR-SunHiNeural` (속도 +10% = 1.1배)
- **자막**: 단어 하이라이트 ASS 번인(100px, 줄당 최대 9자) + SRT 별도 제공

## 업로드용 메타데이터
- **제목**: 방금 산 그거, 당신이 고른 게 아닙니다 🛒 (지갑을 여는 뇌의 착각 3가지)
- **설명**:
  팝콘은 왜 중간 사이즈가 있을까? 9,900원은 왜 싸 보일까? 1+1 앞에서 왜 손해 보는 기분이 들까?
  마트가 당신 뇌를 조종하는 3가지 방법 — 미끼 효과, 왼쪽 자릿수 효과, 손실 회피.
  이번 주에 몇 개나 당하셨나요? 댓글로 알려주세요!
- **해시태그**: #소비심리 #심리학 #뇌과학 #마케팅심리 #절약 #인지편향 #쇼츠 #꿀팁
