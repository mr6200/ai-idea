# 유튜브 쇼츠 대본 — 편의점 1+1, 정말 이득일까?

- 길이: 1분 (60초) + 맨 앞 썸네일 1초, 지식 쇼츠 19편 · TTS 1.2배속, 8장면
- 주제: 돈 · 생활 (사용자가 고름), 스타일: 18편과 같은 3D 클레이 AI(Seedream 4.0) + 인포그래픽 (사용자 선택)
- 아래 구간 시간은 썸네일을 뺀 본편 기준, 실제 영상에서는 1초씩 늦음

---

## 1. 훅 (0:00 – 0:04)

**화면:** 음료 두 병을 든 클레이 남자 / "편의점 1+1, 무조건 이득일까?" + 캔 두 개 → "하나는 공짜?"
> 편의점 1+1, 무조건 이득일까요? 계산해 보면 생각과 달라요.

## 2. 1+1 = 반값 (0:04 – 0:11)

**화면:** 음료 냉장고 / "한 개 값에 두 개 · 개당 50% 할인" → "그런데 정가는?"
> 1+1은 한 개 값에 두 개, 반값에 사는 셈이죠. 그런데 편의점 정가는 대형마트보다 비싼 편이에요.

## 3. 편의점이 약 37% 더 비쌈 (0:11 – 0:18)

**화면:** 마트와 편의점 / "같은 상품 10개 총액 · 한국소비자원 조사 (2020년)" 막대 마트 19,972원 · 편의점 27,325원 → "편의점이 약 37% 더 비쌈", "1+1이어도 마트와 큰 차이 없을 수도"
> 같은 상품 10개를 사 보니 편의점이 약 37% 더 비쌌죠. 그래서 1+1이라도 마트보다 크게 싸지 않을 수 있어요.

## 4. 2+1의 함정 (0:18 – 0:24)

**화면:** 과자 세 봉지를 든 손님 / 캔 세 개 "세 개를 다 사야 할인" → "하나만 필요했다면 = 돈 2배"
> 2+1은 더 조심해야 해요, 세 개를 다 사야 할인이거든요. 하나만 필요했다면 두 배를 쓴 셈이죠.

## 5. 공짜의 힘 (0:24 – 0:32)

**화면:** 초콜릿 가판대 / "미국 MIT 실험 (2007년)" 보통 초콜릿 1센트 · 고급 초콜릿 15센트 → 공짜! · 14센트 → "공짜를 고른 사람 크게 늘어"
> 그래도 끌리는 건 공짜의 힘 때문이에요. 미국 실험에서 초콜릿 값을 1센트 내려 공짜로 만들자, 더 좋은 초콜릿 대신 공짜를 고른 사람이 크게 늘었어요.

## 6. 값 올리고 1+1? (0:32 – 0:41)

**화면:** 가격표를 바꾸는 점원 / "참기름 한 병 4,750원 → 9,500원 · 값을 두 배로 올린 뒤 1+1" → "공정위, 대형마트 4곳 과징금 (2016년)"
> 참기름 값을 4,750원에서 9,500원으로 올리고 1+1을 한 마트도 있었죠. 공정거래위원회가 대형마트 4곳에 과징금을 매겼죠.

## 7. 퀴즈 (0:41 – 0:50)

**화면:** 퀴즈 무대 / "2+1으로 사면 개당 몇 % 할인?" 50% · 33% · 25% → "정답 · 약 33%" → "세 개를 두 개 값에"
> 퀴즈! 2+1으로 사면 한 개에 몇 % 할인일까? 정답은, 약 33%예요! 세 개를 두 개 값에 사니까요.

## 8. 마무리 (0:50 – 1:00)

**화면:** 영수증을 보는 클레이 사람 / "필요한 만큼만, 한 개 가격 따지기" → 구독하기
> 필요한 만큼만, 한 개 가격을 따져 보세요. 더 많은 돈 이야기가 궁금하다면 구독해 주세요.

내레이션 읽기: "1+1" → "원 플러스 원", "2+1" → "투 플러스 원", "10개" → "열 개", "몇 %" → "몇 퍼센트"

## TTS 검사 (`build/tts_check.py` → `build/tts_report.md`, 의심 줄은 Whisper medium으로 다시 확인)

| 처음 문장 | 검사 결과 | 고친 문장 |
|---|---|---|
| (읽기) 1+1, 2+1 | TTS가 「일+1」, 「이+1」로 읽음 | 읽기 규칙 「원 플러스 원」, 「투 플러스 원」 추가 |
| 퀴즈! 2+1로 사면 … | 「투 플러스 원**로**」 — 조사가 어긋남 | 2+1**으로** 사면 |
| 공정위는 대형마트 4곳에 과징금을 매겼어요 | small · medium 둘 다 「**공정인**은」으로 받아씀 | **공정거래위원회가** 대형마트 4곳에 과징금을 매겼죠 (medium 정확) |
| 행사 직전 / 어떤 마트는 4,750원 참기름을 … | medium이 「**4790원**」으로 받아씀 (가격이 틀리게 들릴 위험) | 참기름 값을 4,750원**에서** 9,500원으로 올리고 1+1을 한 마트도 있었죠 (medium 정확) |

그대로 둔 것: 「반값」의 「반」(0.46초/음절), 「한 개」의 「한」(0.44초/음절)은 강조로 살짝 끄는 정도. 「할인일까」를 「할이닐까」로 받아쓴 것은 실제 발음(연음). 받아쓰기 유사도가 낮게 나온 줄은 「1+1」을 「1 플러스 1」로 적은 표기 차이 — medium으로 들어 보면 바르게 읽음.
