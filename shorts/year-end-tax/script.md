- 주제: 사용자 지정 「연말정산」, 각도는 사용자 선택 ("12월 안에 해야 할 것"). 카드 공제율은 「첫 월급」 편, 연금저축 · IRP 자세한 내용은 「연금저축」 · 「연금저축 vs IRP」 편에서 다뤄 짧게만 언급
- 스타일: 웹툰풍 틀 + 액션 세미리얼 그림체 (Seedream 4.0), 같은 직장인 캐릭터, 어두운 자막 상자
- 아래 구간 시간은 썸네일을 뺀 본편 기준, 실제 영상에서는 1초씩 늦음
- 기준: **2026년 11월 확인, 2026년 귀속(2027년 1월 연말정산)**. 다음 해에 다시 쓰려면 고향사랑기부 공제율(2027년 개정안 국회 심의 중) · 미리보기 일정을 다시 확인

## 1. 훅 (0:00 – 0:06)

**화면:** 눈 내리는 12월 사무실에서 놀란 직장인 / "연말정산, 12월에 끝난다!" / 효과음 "땡!" → "승부는 12월 31일"
> 연말정산은 1월에 하는 거 아니에요? 사실 승부는 12월 31일에 끝나요. 1월엔 이미 쓴 돈을 정리만 하거든요.

## 2. ① 연말정산 미리보기 (0:06 – 0:14)

**화면:** 밤에 노트북 앞, 화면에서 떠오르는 금화 · 영수증 / "홈택스 · 무료 · 1~9월 카드 사용액으로 예상 환급액 미리 계산" → "토해낼 것 같으면 지금 손쓰기"
> 첫째, 홈택스 연말정산 미리보기. 9월까지 쓴 카드값으로 예상 환급액을 보여 줘요. 토해낼 것 같으면 아직 손쓸 시간이 있죠.

## 3. ② 연금저축 · IRP (0:14 – 0:23)

**화면:** 황금 돼지 저금통에 동전을 넣는 직장인 / "12월 31일 납입분까지 올해 공제 · 합쳐서 900만 원" → "최대 16.5% 돌려받으면 148만 5천 원"
> 둘째, 연금저축과 IRP는 12월 31일까지 넣은 돈만 올해 공제예요. 합쳐서 900만 원까지, 최대 16.5%를 돌려받아요.

## 4. ③ 고향사랑기부 (0:23 – 0:30)

**화면:** 가을 시골 들판에서 사과 선물 상자를 든 직장인 / 흐름 "기부 10만 → 공제 10만 → 선물 3만" / 효과음 "답례품까지!"
> 셋째, 고향사랑기부제. 10만 원을 내면 10만 원을 세금으로 돌려받고, 3만 원어치 답례품까지 받아요.

## 5. 단, 조건! (0:30 – 0:34)

**화면:** 붉은 경고등 앞에서 손을 든 직장인 / "내야 할 세금(결정세액)이 있어야"
> 단, 내야 할 세금이 있어야 돌려받을 수 있어요.

## 6. 퀴즈 (0:34 – 0:43)

**화면:** 퀴즈 무대 / "10만 원 기부, 다 돌려받으면 실제 부담은?" 10만 원 · 3만 원 · 0원 → "정답!" → "답례품 3만 원만큼 이득"
> 퀴즈! 고향사랑기부로 10만 원을 내고 다 돌려받으면 실제 부담은? 정답은, 부담 0원이에요! 오히려 답례품만큼 이득이죠.

## 7. 마무리 (0:43 – 0:53)

**화면:** 새해 전야 옥상, 불꽃놀이 아래 웃는 직장인 / "마감은 12월 31일!" → 구독하기
> 올해 남은 공제, 12월 31일이 마감이에요. 더 많은 돈 이야기가 궁금하다면 구독해 주세요.

## TTS 검사 (`build/tts_check.py`, 의심 줄은 Whisper medium으로 다시 확인)

| 처음 문장 | 검사 결과 | 고친 문장 |
|---|---|---|
| 단, **낼** 세금이 있어야 … | small · medium 둘 다 「매일 세금」 | 단, **내야 할** 세금이 있어야 … (화면 문구도 같이) |
| 정답은, 0원이에요! | small · medium 둘 다 「0, 1이에요」 | 정답은, **부담** 0원이에요! (`SPOKEN`에 「0원」 → 「영 원」) |
| … 10만 원을 세금**에서** 돌려받고 | 둘 다 「세금해서」 | 세금**으로** 돌려받고 |
| IRP | 영문 약어 | `SPOKEN`에 「아이알피」 |

그대로 둔 것: 「답례품」 → 「담녜품」 · 「담내품」, 「연말정산은」 → 「연말정사는」은 실제 발음([담녜품], [연말정사는])이라 TTS가 맞음. 「홈택스」 → 「홈텍스」 받아쓰기 표기 차이. 경고 3줄은 모두 이 발음 때문 (빨리 감기 0줄).
