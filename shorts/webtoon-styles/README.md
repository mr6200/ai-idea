# 웹툰 그림체 예시 5종 (2026-11-03, 사용자 요청)

25편 첫 장면(셔터가 내려가는 은행 앞으로 뛰어오는 직장인)을 같은 프롬프트로, 그림체만 바꿔 그렸습니다. 지금 쓰는 웹툰풍(23~25편)은 「깔끔한 선 + 셀 채색 + 파스텔」입니다.

| 번호 | 그림체 | 느낌 |
|---|---|---|
| ① | 수채화 감성 | 얇은 선, 수채 번짐, 노을빛. 부드럽고 감성적 |
| ② | SD 개그(치비) | 큰 머리 · 큰 눈, 과장된 표정, 집중선. 가장 코믹 |
| ③ | 흑백 만화(스크린톤) | 잉크 선 + 망점, 넥타이만 빨강. 강렬하고 눈에 띔 |
| ④ | 액션 세미리얼 | 영화 같은 조명, 진한 색. 극적이고 묵직함 |
| ⑤ | 심플 일상툰(인스타툰) | 단순한 선, 동글동글한 얼굴, 여백. 친근하고 가벼움 |

- 그림: `gen.py` (Seedream 4.0, 5장 × $0.027 ≈ $0.14), 글씨 얹기와 비교표: `compose.py` → `styles_sheet.png`
- 예시라 배경 간판의 엉터리 글씨는 고치지 않음. 실제 편에서는 "no signboard" 프롬프트와 다시 그리기로 처리
