## 이번 편 메모

- 실용형 주제라 마지막 장면에 조회 순서(① 어카운트인포 ② 내보험찾아줌)를 카드로 넣고, 설명란에 「바로 조회하기」를 둠
- TTS: 「잠든」 → 「잡는」, 「내 계좌를」 → 「4개자를」, 「내보험찾아줌에서」 → 「찾아주면서」로 small · medium 둘 다 받아씀 → 말을 바꿔 해결 (`script.md`)
- 화면 숫자와 내레이션 숫자를 같은 단위로 맞춤 (보험금 5.8조 = 5조 8천억)
- 자막 글자 크기는 58px이라 한 줄에 한글 약 15자까지. 넘으면 3줄로 나눔
