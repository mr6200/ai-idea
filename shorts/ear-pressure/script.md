# 유튜브 쇼츠 대본 — 비행기 타면 귀가 먹먹한 이유

- 길이: 1분 30초 (9:16 세로), 지식 쇼츠 10편 · 1분 30초 규격(90초, TTS 1.2배속, 12장면)
- 스타일: 설계도+팝아트. 자막 도현, 제목 Black Han Sans, 감탄사 Jua. 오른쪽 아래 표제란 없음 (10편부터)
- 톤: 빠르고 또렷한 지식 채널 내레이션, 짧은 문장. 9편(비행기 창문)과 이어지는 기압 이야기

---

## 1. 훅 (0:00 – 0:05)

**화면:** 큰 귀 + "웅~" "먹먹" → "범인은 귀 속 공기!" 말풍선
> 비행기만 타면 귀가 먹먹하죠? 범인은 귀 속 공기예요.

## 2. 귀 속 구조와 기내 기압 (0:05 – 0:19)

**화면:** 귀 단면 설계도(바깥귀 통로·고막·중이·이관) → "바깥 기압 = 안쪽 기압" / 산과 비행기, 치수선 2,400m → "산 위와 비슷한 기압"
> 고막 안쪽에는 중이라는 작은 공기 방이 있어요. 평소엔 고막 안팎의 기압이 같아요.
> 그런데 비행기 안은 땅보다 기압이 낮아요. 높이 2,400m 산 위와 비슷한 수준이에요.

## 3. 먹먹해지는 이유와 해결사 (0:19 – 0:41)

**화면:** 고막이 밀림 + "팽팽!" → "소리가 먹먹해져요" / 이관 강조 → "평소엔 닫혀 있어요" / "꿀꺽!" "하~암" → 이관 열림, 공기 이동 → "뻥!"
> 기압이 바뀌면 고막 안팎의 압력이 달라져요. 고막이 밀려 팽팽해지면 소리가 먹먹해져요.
> 해결사는 귀와 코 뒤를 잇는 가는 통로, 이관이에요. 이관은 평소엔 닫혀 있어요.
> 침을 꿀꺽 삼키거나 하품하면 이관이 잠깐 열려요. 공기가 드나들며 뻥 하고 풀리죠.

## 4. 이륙과 착륙의 차이 (0:41 – 0:55)

**화면:** 올라가는 비행기, 공기가 이관으로 빠져나감 → "저절로 빠져나가요 · 쉬움" / 내려가는 비행기, 고막이 안으로 밀리고 이관에 X → "아야!"
> 올라갈 땐 귀 속 공기가 저절로 빠져나가요. 그래서 이륙 때는 비교적 괜찮아요.
> 내려갈 땐 공기가 귀 속으로 들어가야 하는데, 이관이 잘 안 열려서 착륙 때 더 아파요.

## 5. 대처법 (0:55 – 1:10)

**화면:** 네 칸 팁(침 삼키기 · 하품·물 · 껌 · 코 막고 살살 콧바람) / 아기 얼굴 + 이관 굵기 비교 + 젖병 → "젖병 · 쪽쪽이로 꿀꺽"
> 그러니 착륙 전엔 침 삼키기, 하품, 껌, 물 마시기. 코를 막고 살살 콧바람을 불어도 돼요.
> 아기는 이관이 좁아서 더 힘들어해요. 이착륙 때 젖병이나 쪽쪽이로 삼키게 해 주세요.

## 6. 퀴즈 + CTA (1:10 – 1:30)

**화면:** "착륙 때 잠들면 귀가 더 아플까?" O/X → O 정답 → "자는 동안 침을 덜 삼켜요" → 구독 버튼
> 퀴즈! 착륙 때 잠들어 있으면 귀가 더 아플까? 정답은 O! 더 아플 수 있어요. 자는 동안엔 침을 덜 삼키기 때문이에요.
> 다음 비행 때 귀가 먹먹하면 꿀꺽 삼켜 보세요. 더 많은 지식이 궁금하다면 구독해 주세요.

내레이션 읽기: "정답은 O!" → "정답은, 그렇다!", "2,400m" → "이천사백 미터", "이착륙" → "이륙과 착륙"
