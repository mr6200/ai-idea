## 이번 편 메모

- **타이밍형 목록:** "12월 31일까지 할 것" ①②③ (미리보기 · 연금저축/IRP · 고향사랑기부) + 조건 + 퀴즈. 앞 편과 겹치는 카드 공제율 · 연금 상품 설명은 뺌
