## 이번 편 메모

- **상표:** 프롬프트에 "no logos"를 넣어도 Seedream이 실제 로고(골든 아치)를 그림 → "무늬 없는 줄무늬 차양, 글자 · 기호 없는 가게"로 바꾸고 다시 그림. 기업 주제는 그림을 꼭 눈으로 확인
- **사람 이름:** 「소네본」은 「손해본」처럼 들려 내레이션에서 빼고 화면 글자로만 보여 줌
- **출처가 불확실한 명언:** "햄버거가 아니라 부동산 사업"은 원출처가 없어 "영화 「파운더」 속 대사"로 밝힘
- **숫자:** 2024년 10-K 재무 표의 공식 수치(임대료 100억 · 로열티 56억 달러)를 씀. 2025년 수치는 보조 자료라 표에만 적음
