## 이번 편에 적용한 사용자 규칙

- 주제는 사용자가 직접 제안 (첫 「비교」 편)
- 실제 사진 9장면 (CC0 · CC BY-SA, 화면과 설명란에 작가 · 라이선스), AI 영상 3장면, AI 사진 2장면
- 썸네일 전에 제목을 물어봄 → 추천안 「이집트 vs 멕시코, 피라미드의 차이」
- 퀴즈 없음, 썸네일 포함 62.5초, 화면 위 라벨에 편 번호 없음

## 새로 만든 것

- **반반 썸네일 `split_background()`** (`gen_thumbnail.py`): 실제 사진 두 장(기자 · 치첸이트사)을 반씩 잘라 나란히 놓고 가운데 흰 선 — 비교 주제에 씀
- **`real_tag()`가 긴 출처에 맞춰 글씨를 줄임** (36 → 최소 24px): 작가 이름이 긴 사진도 한 줄에 들어감

## 이번 편 메모

- 영어 위키백과 글 5개(기자 · 태양의 피라미드 · 촐룰라 · 엘 카스티요 · 비문의 신전)에 쓰인 사진을 `generator=images` + `prop=imageinfo`로 물어, CC BY-NC · 라이선스 없는 사진은 걸러 냄
- 이집트 피라미드는 지금 계단처럼 보여서 「원래 면이 매끈했다」고 말함 (겉 석회암이 대부분 사라짐)
- 촐룰라 꼭대기 교회의 연대는 자료마다 달라(1574~75년 / 1864~74년 재건) 「스페인 정복 뒤에 세움」으로만 씀
