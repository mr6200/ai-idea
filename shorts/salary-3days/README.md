## 스타일: 웹툰풍 (23편, 사용자 선택)

18~22편의 3D 클레이가 반복돼 새 스타일 예시 4종(A 웹툰 · B 레트로 픽셀 · C 종이 콜라주 · D 화이트보드)을 같은 장면으로 보여 드렸고, **A 웹툰풍**을 고르셨습니다. 예시 장면 「월급, 왜 3일 만에 사라질까?」를 그대로 주제로 씀.

| 요소 | 규칙 (`build/gen_scenes.py`) |
|---|---|
| 그림 | Seedream 4.0 웹툰풍 (`gen_backgrounds.py`의 `STYLE`). **같은 캐릭터**를 모든 프롬프트에 똑같이 적음 (`CHAR`: 짧은 검은 머리 · 흰 셔츠 · 남색 넥타이의 젊은 직장인) → 7장면 내내 같은 인물로 나옴 |
| 테두리 | 검은 웹툰 칸 테두리 16px, 위쪽 검은 라벨 칩 (`bg()`) |
| 제목 | Black Han Sans, 흰색/노랑 `#ffe14d`, 굵은 검은 외곽선 (`head()`) |
| 말풍선 | 흰 풍선 + 검은 테두리 + 꼬리, Jua (`bubble()`) |
| 효과음 | 기울어진 Jua, 빨강 + 흰 · 검은 이중 외곽선 (`sfx()`: 털썩, 쑥!, 정답!) |
| 카드 · 알약 | 흰 바탕 + 검은 8px 테두리 + 검은 그림자 (`card()`, `pill()`), 폭발 모양 (`burst()`) |
| 자막 | 웹툰 대사 상자: 흰 상자 + 검은 8px 테두리 + 검은 그림자, 도현 58px 검은 글씨 (`gen_subtitles.py`) |
| 비네트 | 밝은 그림에 맞게 약하게 (`compose_bg.py`, 검정 50) |
| 배치 | **말풍선 · 카드가 얼굴을 가리지 않게** 시험 프레임으로 확인하고 옮김 (말풍선은 인물 옆 빈 곳, 카드는 아래쪽) |

## 이번 편 메모

- 웹툰은 인물이 화면을 크게 차지해서 클레이보다 얼굴 가림이 잦음 → 시험 프레임 확인이 더 중요
- AI 그림 속 숫자(달력 「16」)가 퀴즈 숫자(14일)와 헷갈릴 수 있어 빈 달력으로 다시 그림
- TTS: 「기분 탓」 · 「갚는」 · 「고정비와」 · 「3일보다」를 바꿈 (`script.md`)
