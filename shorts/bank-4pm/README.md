# 25편 · 은행은 왜 4시에 문을 닫을까? (48초 · 웹툰풍)

- 48초 + 맨 앞 썸네일 1초 (60초는 최대 길이, 마지막 말 뒤 약 2.5초에서 끝냄), 7장면, TTS `ko-KR-Chirp3-HD-Charon` 1.2배속
- 24편 `shorts/first-salary/`를 틀로 씀 (같은 웹툰 스타일, **같은 캐릭터** `CHAR` + 은행원 `TELLER`)
- 대본 · 사실 확인 · TTS 검사: `script.md` / 업로드 정보: `youtube-metadata.md` / 콘티: `storyboard.html` · `.png`
- 완성 영상: `video/bank-4pm-shorts.mp4`, 썸네일: `thumbnail/thumbnail.png`

## 이번 편 메모

- **영업시간 카드 `hours()`:** 기간 이름과 큰 시간(9:30~15:30)을 줄마다 보여 주는 도우미 (S04 · S05)
- **시각 읽기:** `NATIVE_COUNTERS`에 「시」를 넣어 「4시」를 「네 시」로 읽게 함 (전에는 「사 시」)
- **AI 그림 글씨:** 은행 간판에 엉터리 글씨가 나와 S01 · S07을 "간판 없음, 글씨 없음"으로 다시 그림
- **얼굴 가림:** S04 · S05 시간 카드가 얼굴을 가려 위(y=440)로 올리고, S06 퀴즈 보기는 아래(y=780부터)로 내림
- **빨리 감기 연쇄:** 앞 줄이 늦게 끝나 뒤 줄 3개가 최대 1.11배로 빨라져 c5부터 자막 시간을 다시 배치 (길이 46 → 48초)
- **시간이 지나면 고칠 것:** "내년 4월부터"는 2027년 4월 기준 (`script.md`)
