## 이번 편에 적용한 사용자 규칙

- **실제 자료 9장면** (필사본 페이지 6 · 보이니치 사진 · 루돌프 2세 초상, 모두 공공 영역), AI 영상 3장면, AI 사진 4장면 → 지금까지 실제 자료가 가장 많은 편
- 썸네일 전에 제목을 물어봄 → 사용자가 직접 적은 「600년간 아무도 해석하지 못한 책이 있다?」
- 퀴즈 없음, 썸네일 포함 59.5초, 화면 위 라벨에 편 번호 없음
- 주제 후보에서 앨커트래즈 · 퉁구스카 · 코팅리를 뺌 (사용자 요청)

## 이번 편 메모

- 영어 위키백과 글에 쓰인 그림을 `generator=images` + `prop=imageinfo`로 한 번에 물어 라이선스까지 받음 (요청 한 번)
