# 쇼츠용 한글 글꼴

모두 SIL Open Font License 1.1 (상업적 이용 가능, 같은 폴더의 `OFL-*.txt`). 구글 폰트 저장소(github.com/google/fonts)에서 받음.

| 파일 | 글꼴 이름 (SVG `font-family`) | 쓰임 |
|---|---|---|
| `BlackHanSans-Regular.ttf` | `Black Han Sans` (검은고딕) | 굵은 제목 (시네마틱·콜라주) |
| `DoHyeon-Regular.ttf` | `Do Hyeon` (도현) | 설계도 스타일 |
| `Jua-Regular.ttf` | `Jua` (주아) | 팝아트 만화 스타일 |
| `NanumPenScript-Regular.ttf` | `Nanum Pen` (나눔손글씨 펜) | 손글씨 메모 |

설치: `mkdir -p ~/.fonts && cp shorts/fonts/*.ttf ~/.fonts/ && fc-cache -f`
